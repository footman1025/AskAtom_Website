# AskAtom Solutions — Company Website

React website for AskAtom Solutions LLC: web, mobile, SaaS, AI and automation development.

## What's inside

```
index.html          Vite entry page
src/                React source code
  App.jsx           Page assembly
  styles.css        All styling (colors, animations, layout)
  data/company.js   Stats, clients, case studies, industries, about, FAQ
  data/products.js  8 work areas x 8 project types, with descriptions — edit text here
  components/       Navbar, Hero, Work (tabs + cards), ProductModal,
                    Process, Reviews, Contact (form), Footer
public/
  images/           64 portfolio photos (8 per category)
  badges/           Official Freelancer.com badges (Verified, Preferred, Shareholder)
  favicon.svg       "A" site icon
dist/               Production build (generated by `npm run build`, not committed)
```

## Run locally

```bash
npm install     # once, installs React + Vite
npm run dev     # dev server with hot reload
```

## Build for hosting

```bash
npm run build   # regenerates dist/
```

Upload the contents of `dist/` to any static hosting (Netlify, Vercel, cPanel,
GitHub Pages, S3…). No server required.

## Before launch — checklist

- [ ] Optional: wire the contact form to Formspree/Web3Forms so submissions
      arrive automatically instead of via the visitor's email app
- [ ] Review product descriptions in `src/data/products.js`
- [ ] Check every [sample] value in `src/data/company.js` (stats, case studies,
      founded year, team size, story). They were filled in as examples. Replace
      each with the real figure and remove the brackets.
- [ ] Check reviewer names in `src/components/Reviews.jsx` (three are samples)
- [ ] Photos in `public/images/site/` are public domain / CC0 (Wikimedia Commons), no credit needed
